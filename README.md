# Менеджер списку фруктів (Lists.py)



> Простий консольний додаток на Python для інтерактивного керування списком продуктів у реальному часі.


Детальний опис кожної функції доступний у файлі: [Документація функцій](DOCUMENTATION.md)


## Короткий опис

Ця програма дозволяє користувачеві в циклі додавати нові елементи до списку за допомогою введення з клавіатури, одразу бачити поточний стан списку та завершити роботу за допомогою команди exit.

## Плани розвитку
- [x] Додати базову логіку додавання елементів до списку
- [x] Реалізувати функцію виведення списку на екран
- [x] Налаштувати вихід із програми за командою exit
- [ ] Додати перевірку на введення порожніх рядків
- [ ] Зробити збереження списку у файл



## Функціональність

\* Інтерактивне введення даних через консоль.

\* Функція збереження та додавання елементів (add\_food).

\* Функція виведення поточного стану списку на екран (show\_food).

\* Перевірка команди виходу незалежно від регістру (exit).

## Таблиця функцій
| Назва функції | Опис | Приклад виклику |
| :--- | :--- | :--- |
| `show_food()` | Виводить поточний стан списку `cheky` на екран | `show_food()` |
| `add_food()` | Додає поточне значення `food` до списку `cheky` | `add_food()` |



## Інструкції з встановлення

1\. Переконайтеся, що у вас встановлено Python (рекомендується версія 3.10 або вище).

2\. Завантажте файл Lists.py у свою робочу директорію.

3\. Відкрийте термінал або командний рядок у папці з файлом.



## Приклад використання

Запустіть скрипт у терміналі за допомогою команди:



```bash

python Lists.py
Що додати до списку або 'exit': яблуко

Список фруктів: \['яблуко']

Що додати до списку або 'exit': банан

Список фруктів: \['яблуко', 'банан']

Що додати до списку або 'exit': exit

Список: \['яблуко', 'банан']
```
